Quantile cycles

A counterexample in distributional reinforcement learning.

Question

Quantile-based distributional RL, as in QR-DQN, represents each action’s return distribution by a few quantiles and acts greedily on their mean. For evaluating a fixed policy, the quantile-projected Bellman update is known to converge. Does it converge for control, when the greedy action can change from one update to the next?

Result

No. For every number of quantiles K ≥ 2 there is a one-state, two-action problem where the update has no fixed point. From any starting point it falls into a two-step cycle that alternates between the optimal action and a worse one, forever. The optimal policy is unique and the cycle needs no ties, so this is not an artifact of tie-breaking.

The smallest case uses two quantiles and discount 1/4. Action A always pays 91/128. Action B pays 0, 1/2 or 1 with probabilities 3/16, 1/2 and 5/16. A is better by 19/128 in expected reward, and always choosing B loses 19/96 in discounted value. But the projected means make A look better by 3/128 in one phase and B look better by 3/128 in the next, so the greedy choice flips back and forth. The repository has a diagram of both phases with every exact value.

Checks

The proof is written out in the repository. Separately, every finite instance is checked in exact rational arithmetic: 18 one-state instances (K from 2 to 16, then 32, 64 and 128), the five fixed-discount instances above, and 18 trajectories started from zero. One command, python -B verify.py, reproduces all of them in seconds using only the standard library. The general proof has not been checked in a proof assistant.

Prior work

Rowland et al. (2019, appendix B.4) showed that quantile means can strictly prefer a worse action for any K, in a one-step setting. Bellemare, Dabney and Munos (2017) and the Distributional RL book (example 7.11) showed that distributional control can cycle, using a chosen rule for breaking ties between equally good actions. What is new here is the combination: a recurring strict cycle, a unique optimal action and no fixed point, for every K.
