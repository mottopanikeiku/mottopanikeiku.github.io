Projects

  • 2026

    Aperture

    LLM serving latency

    Time to first token for Qwen3.6-27B-FP8 on a single 48 GB RTX 6000 Ada. Cold 3,072-token prompts come back in under a second at p99. At 4,096 tokens it takes 1.09 s, with 78% of kernel time in FP8 matrix multiplies; retuning those kernels for Ada took about 10% off. A reused 4,096-token prefix returns its first token in 117 ms.

    803 ms p99, cold 3,072-token prompt1

  • 2026

    HeliosTune

    GPU kernel autotuning

    A retrieval-first Bayesian autotuner for Triton kernels, built to test whether timing data from cheaper GPUs (L4, A10, T4) can warm-start tuning on an H100. On held-out workloads it couldn’t: the selected transfer weight was zero, and a plain cold-start tuner did slightly better. The repository publishes the negative result with the data to reproduce it.

    0 transfer weight selected2

  • 2026

    BranchPilot

    Adaptive sampling for LLMs

    Self-consistency samples a model several times and keeps the majority answer. BranchPilot decides after each sample whether another is worth paying for, with fixed, rule-based, or learned stopping strategies behind an OpenAI-compatible gateway. On the full GSM8K test set the learned policy failed its prespecified success rule; simpler rules chosen on validation did better.

    1,319 GSM8K test problems3
